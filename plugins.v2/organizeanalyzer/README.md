# 媒体整理异常分析插件 (OrganizeAnalyzer)

## 简介
本插件用于定期或手动扫描 MoviePilot 的媒体整理历史记录 (`TransferHistory`)，自动分析识别出媒体整理过程中出现的各种隐蔽或常见异常，方便用户快速定位修复，提高媒体库整理规范性与正确率。

## 支持的异常检测类型
1. **多文件合并覆盖冲突** (`merged_files`)：多个源文件被整理/合并到了同一个目标文件中（可自定义阈值，默认 $\ge 2$）。
2. **英文未中文化标题** (`english_title`)：整理出的标题不含中文字符或与源文件名一致（未识别中文别名或识别回退）。
3. **未识别/TMDB ID 缺失** (`unidentified`)：TMDB ID 为空/0 或标题包含“未知”的整理条目。
4. **整理运行失败** (`failed_status`)：状态为 `status=False` 或带有 `errmsg` 报错原因的历史条目。
5. **重复季集冲突** (`duplicate_episode`)：同一剧集的同一季集（如 S01E01）被多次整理到了不同的目标路径。
6. **目标物理文件缺失/0字节** (`missing_dest`)：整理记录在库但目标物理文件已丢失或大小为 0 字节（仅本地绝对路径支持）。
7. **离群/格式异常集数** (`invalid_episode`)：集数数值解算过大（如 $> 500$）。

## 核心功能
* **增量/全量扫描**：支持基于上次运行时间戳的增量检测及全量检测。
* **定时任务 (Cron)**：后台定时自动检测。
* **消息通知**：可配置分析完成后自动推送 Telegram / 微信 / Webhook 汇总分析结果。
* **白名单与忽略**：支持配置忽略路径关键字，并可在 API/界面中手动标记“已忽略”条目。
* **仪表盘集成**：直接在 MoviePilot 首页/仪表板展现未处理异常统计指标。

## 配置参数说明
* **启用插件**：开启/关闭插件。
* **分析完成后发送系统通知**：开启后，自动推送包含异常摘要及样本条目的消息报告。
* **定时分析 Cron 表达式**：默认 `0 3 * * *`（每天凌晨 3:00 自动运行增量分析）。
* **多文件合并阈值**：判定多文件合并的最小源文件数量（默认 $\ge 2$）。
* **忽略路径关键词白名单**：包含指定字符串的 `src` 或 `dest` 路径将跳过检测（英文逗号分隔）。
